\begin{resumo}[Abstract]
  The complexity of graphical user interfaces has intensified the challenges faced by software test automation tools, which are traditionally code-based, as well as by more recent approaches that incorporate or use Artificial Intelligence (AI) to support test generation. In modern applications, identifying and accessing graphical user interface elements has become increasingly difficult, since identifiers are often ambiguous, dynamic, or unstable, which compromises the automatic generation of test code and may result in faulty or unreliable tests. In this context, different AI-based strategies, such as the use of Large Language Models (LLMs), Natural Language Processing (NLP) techniques, and AI agents, have been explored in order to mitigate the problems related to identifying interface elements. Given this scenario, this study aimed to investigate how Behavior-Driven Development (BDD) specifications should be written and detailed so that AI-based systems can identify graphical user interface elements and generate executable automated test code. To achieve this goal, a structured literature review based on the systematic review protocol was conducted, and, as a follow-up to the research, a retrospective observational study was planned, following the case study protocol and using the CAPJU project as the case, with the aim of investigating the application of these techniques to address the challenges associated with automatic test generation. The analysis carried out makes it possible to discuss the implications of the investigated approach, its limitations, threats to validity, and opportunities for future work, contributing to the advancement of test automation practices.

\textbf{Palavras-chave:} Keywords: Test Automation; Artificial Intelligence; Behavior-Driven Development; Automatic Code Generation; Graphical User Interfaces.
\end{resumo}
