\chapter{Uso de Inteligência Artificial no Estudo}
\label{ch:inteligencia}

Foi utilizada a ferramenta ChatGPT (GPT-5.3) com o prompt “Escreva corretamente em português este texto, sem adicionar ou remover conteúdo”, ou variações equivalentes, como apoio à revisão linguística de trechos do texto. Adicionalmente, o GitHub Copilot foi utilizado no Visual Studio Code para auxiliar na compreensão da arquitetura do CAPJu e no desenvolvimento de uma implementação exploratória, com o objetivo de verificar a viabilidade da adaptação pretendida para a extensão Cypress Copilot.
