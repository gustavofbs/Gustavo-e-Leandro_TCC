\begin{resumo}
    A complexidade das interfaces gráficas tem intensificado os desafios enfrentados pelas ferramentas de automação de testes de software, tradicionalmente baseadas em código, bem como pelas abordagens mais recentes que incorporam ou utilizam Inteligência Artificial (AI) para apoiar a geração de testes. Em aplicações modernas, a identificação e o acesso aos elementos da interface gráfica tornam-se cada vez mais difíceis, uma vez que os identificadores são frequentemente ambíguos, dinâmicos ou pouco estáveis, o que compromete a geração automática de código de teste e pode resultar em testes defeituosos ou pouco confiáveis. Nesse contexto, diferentes estratégias baseadas em AI, como o uso de Grandes Modelos de Linguagem (LLMs), técnicas de Processamento de Linguagem Natural (NLP) e agentes de AI, têm sido exploradas com o objetivo de mitigar os problemas relacionados à identificação de elementos na interface. Diante desse cenário, este estudo teve como objetivo investigar de que maneira as especificações de Desenvolvimento Orientado por Comportamento (BDD) devem ser escritas e detalhadas para que sistemas baseados em AI consigam identificar os elementos da interface gráfica e gerar código de teste automatizado executável. Para alcançar esse objetivo, foi conduzida uma revisão estruturada da literatura, baseada no protocolo de revisão sistemática, e, como desdobramento da pesquisa, foi planejado um estudo observacional em retrospectiva, seguindo o protocolo de estudo de caso, utilizando como caso o projeto CAPJU, com o intuito de investigar a aplicação dessas técnicas na resolução dos desafios associados à geração automática de testes. A análise realizada permite discutir as implicações da abordagem investigada, suas limitações, ameaças à validade e oportunidades para trabalhos futuros, contribuindo para o avanço das práticas de automação de testes.

\textbf{Palavras-chave:} Automação de Testes; Inteligência Artificial; Desenvolvimento Orientado por Comportamento; Geração Automática de Código; Interfaces Gráficas.
\end{resumo}
